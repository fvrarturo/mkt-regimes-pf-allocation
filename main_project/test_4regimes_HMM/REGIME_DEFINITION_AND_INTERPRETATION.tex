\section{Regime Definition Process}

\subsection{Features Used (4 Total)}

The HMM uses \textbf{only 4 features}:
\begin{itemize}[leftmargin=*]
    \item \textbf{Macro (2)}: \texttt{gdp}, \texttt{PCE\_price\_index} (prefer \texttt{zscore\_pct\_change\_mom})
    \item \textbf{Sentiment (2)}: \texttt{ec\_growth\_sentiment}, \texttt{inflation\_sentiment}
\end{itemize}

\subsection{Processing Pipeline}

\begin{enumerate}[leftmargin=*]
    \item \textbf{Standardization}: Macro and sentiment features standardized separately
    \item \textbf{Weighted Combination}: \texttt{combined = macro\_scaled * 0.4 + sentiment\_scaled * 0.6}
    \item \textbf{HMM Discovery}: Gaussian HMM with diagonal covariance discovers 4 hidden states (10 random initializations)
\end{enumerate}

\subsection{Regime Interpretation}

After HMM discovery, regimes are assigned to quadrants:

\begin{itemize}[leftmargin=*]
    \item \textbf{Growth Proxy} = mean(\texttt{gdp}, \texttt{ec\_growth\_sentiment})
    \item \textbf{Inflation Proxy} = mean(\texttt{PCE\_price\_index}, \texttt{inflation\_sentiment})
\end{itemize}

\textbf{Assignment}: Regimes classified using \textbf{absolute thresholds} relative to historical mean (zero):
\begin{itemize}[leftmargin=*]
    \item \textbf{High Growth} = \texttt{avg\_growth >= 0} (above average)
    \item \textbf{Low Growth} = \texttt{avg\_growth < 0} (below average)
    \item \textbf{High Inflation} = \texttt{avg\_inflation >= 0} (above average)
    \item \textbf{Low Inflation} = \texttt{avg\_inflation < 0} (below average)
\end{itemize}

\subsection{Actual Regimes Discovered}

Based on the data, the following regimes are identified:

\begin{enumerate}[leftmargin=*]
    \item \textbf{High Growth / High Inflation}: Expansion with Rising Prices (monetary tightening) - R1
    \item \textbf{High Growth / Low Inflation}: Goldilocks Economy (best for risk assets) - R2
    \item \textbf{Low Growth / Low Inflation}: Recession/Deflation (monetary easing, fiscal stimulus) - R0 (moderate), R3 (extreme)
\end{enumerate}

\textbf{Note}: The ``Low Growth / High Inflation'' (Stagflation) quadrant is \textbf{not present} in the current data. All Low Growth regimes have below-average inflation.

\section{Scatter Plot Interpretation}

\subsection{Value Meaning}

Axes show \textbf{standardized values} relative to historical mean:
\begin{itemize}[leftmargin=*]
    \item \textbf{0} = Historical average
    \item \textbf{Positive} = Above average
    \item \textbf{Negative} = Below average
\end{itemize}

\subsection{Calculation}

\begin{itemize}[leftmargin=*]
    \item \textbf{Average Growth (X-axis)} = mean(\texttt{gdp}, \texttt{ec\_growth\_sentiment})
    \item \textbf{Average Inflation (Y-axis)} = mean(\texttt{PCE\_price\_index}, \texttt{inflation\_sentiment})
\end{itemize}

\textbf{Note}: Values mix z-scored macro data (mean=0, std=1) with raw sentiment scores, so axes represent relative positioning, not pure z-scores.

\subsection{Regime Positions}

\begin{itemize}[leftmargin=*]
    \item \textbf{R1 (Top-Right)}: High Growth / High Inflation
    \item \textbf{R2 (Bottom-Right)}: High Growth / Low Inflation
    \item \textbf{R0 (Bottom-Left)}: Low Growth / Low Inflation
    \item \textbf{R3 (Far Bottom-Left)}: Low Growth / Low Inflation (extreme)
\end{itemize}

\textbf{Reference Lines}: Dashed lines at 0.0 separate High/Low Growth (vertical) and High/Low Inflation (horizontal).
