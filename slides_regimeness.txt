Here are the plots and data for the regimeness part. The structure goes as follows: we want to try regression forecasting of ERP conditional on specific macro regimes. To do so, we try two models
1.⁠ ⁠Model definition: WE define a 2x2 hard threshold model based on literature and an HMM model that automatically finds the best regime definitions for a given subset of macro variables to test and number of regimes desired (variable K). We then selected an HMM model with a very good information criterion AIC/BIC (i.e. model that separates very well the regimes) while having a reasonably small number of regimes K=4 to reduce overfitted definitions of regimes and keep interpretability high (you can add the 3D plot in appendix)
2.⁠ ⁠⁠Conditional regressions: Based on our regime definitions, we train lasso regressions on same macro variables as full regression’s dataset. For hard threshold, exactly the same procedure. For soft thresholds, we use weighted regressions as explained by Gloria. In sample and out of sample results in .txt file 
3.⁠ ⁠⁠Trading strategy: We start at a period T by taking the values of Growth Inflation factors, which defines the regime we’re in / mix of regimes we’re in. Then, we run the regression / weighted regression to forecast next period ERP based on this period’s macro variables. We then trade according to the strategy Weight = 50% + 25% * Z_score of ERP_Forecast (over last year). We see that the best strategy is the 2x2, the HMM got stuck in a very cautious position post covid as macro variables were pretty different, making it avoid good returns.
